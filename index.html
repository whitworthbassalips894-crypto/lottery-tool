六、如何验证前瞻统计是否正确 ## 六、精确检验、起算期和随机对照 「6. 前瞻验证」默认起算期 `2026-201`（模型参数冻结点）： Section 6 默认仍从 `2026-201` 开始，但这只是评估区间默认值，**不代表参数在该期前已冻结**。当前默认已恢复原评分和原选码；组合约束仅作可选实验。“每期不偷看”不能消除历史调参或选择偏差。 1. **无未来信息**：验证第 N 期时只把第 N 期**之前**的数据喂给模型（等价于历史回放的 `longWaveEngine(draws.slice(0,i))`）。可以用肉眼抽查：页面上 2026-201 的 7 码应与"历史回放"中该期的固定 7 码完全一致。 2. **追加数据不改历史预测**：一键同步/粘贴导入追加了 2026-202 之后的数据后，2026-201 等早期期次的预测 7 码应保持不变（可截图对比）。 3. **统计量自检**：样本期数 n、命中 h、命中率 h/n、随机期望 = n×14.29%、超额 = h−期望、z = (h−期望)/√(n×p×(1−p))、单边 p 值可用任意正态计算器对照（如 z=1.96 → p≈0.0250）。 4. **明细逐行可查**：每期列出当期 7 码、实际特码、是否命中、单双/大小/波色是否命中，可人工复核。 5. **整体校验**：一期 7 码的随机命中概率恒为 7/49≈14.29%；把起算期改成更早日期（如 `2026-001`），样本期数应随之变大且历史回放中该年的总命中数一致。 ### 精确二项右尾检验 - 原假设：各期开奖独立且特码在 1–49 中均匀分布；每期固定7个不同候选，单期命中概率 `p0 = 7/49 = 1/7`。 - `N` 为实际回放期数、`K` 为命中次数，主检验为 `P[Binomial(N, 1/7) >= K]`，包含等号。 - `binomialRightTail()` 用 log PMF 递推和 log-sum-exp 累加右尾，不计算阶乘，不使用 `1-CDF` 相减，避免溢出、下溢和尾部消减误差。超出浮点表示范围的极小尾概率显示为 `<1e-300`，不显示为“概率绝对为零”。 - 连续性修正 `z = (K − N/7 − 0.5) / sqrt(N × (1/7) × (6/7))` 仅作参考，**不参与显著性判定**。 - 只有精确 `p < 0.05` 才标为“统计显著（单一区间、未校正）”；`0.05 <= p < 0.10` 为“边缘 / 不显著（可能为随机波动）”；其余不显著。 - 例如 `N=58, K=13`：精确 `p ≈ 0.06298880271203224`，不能标为显著；`K=14` 时约 `0.03135150682202337`。 - 无样本时不显示 p/z、不运行模拟；`K=0` 时精确右尾为1。命中率不是收益率。 ### 动态起算期 - 可输入期号或拖动滑块；两者同步，输入防抖后自动重算。 - 起算期只改变评估区间，预测当期仍使用**全部此前历史**。模型最少需要60期预热，实际有效区间会显示出来。 - 与 Section 4 共享逐期预测缓存；同一数据版本切换起点只做切片和重新统计，不重复计算整个引擎。 - 错误/超出范围的期号明确报错，不静默回退默认起点；追加、撤销、修复、导入数据后缓存和区间边界都会更新。 - 反复拖动、重复查看、事后择优区间属于探索性分析，**不能自动防止基准期偏误**。本页没有多重检验校正；正式验证必须提前固定版本、起算期、观察期限，使用未来未见数据。 ### 蒙特卡洛10,000次随机对照 - 按当前相同的 `N`，模拟10,000个模型，每个模型每期独立均匀抽7个不同号码，以 `命中次数 >= K` 的比例作为 `p_emp`。 - 实现采用与抽7元素子集在命中次数上**完全同分布**的独立 `Bernoulli(1/7)`，避免构造无用的完整号码集合；对照组不应用实验模型的组合约束。 - PRNG 为 Mulberry32，随机种子由浏览器随机源生成并显示，可复现。计算分批让出主线程，显示进度。 - 展示超过次数、经验p值、模拟比例的95% Wilson区间和精确p值；区间衡量模拟误差，不是模型胜率区间。即使超过次数为0，也不代表真实概率为0。 - 切换区间、切换组合约束或更新数据立即取消旧任务并清空旧结果，防止统计串区间。模拟不是一份新的实证，显著性仍只由精确检验决定。 - 明细仅保留期号、当期7码、实际特码、7码命中，不恢复单双/大小/波色的前瞻回测列。 ##
