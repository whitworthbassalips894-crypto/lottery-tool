# 三中三 · 7码复式工具

页面采用原工具的卡片式设计，核心选号算法移植自用户提供的《三中三(2).html》，只使用每期前6个平码，忽略第7球。展示主推7码、期号、一键复制、历史回放及开奖数据同步；不展示附件里的热度及额外策略面板。

- 7码可拆分为35个三数组合，命中组数为 C(命中的号码数, 3)。开奖随机，模型不保证中奖；回放依用户提供口径以每组2元、中奖总返奖700倍计算：35组每期70元，每个中奖组合奖金1,400元（含本金），未计税费；实际赔率、奖金及费用请以当地合法销售机构规定为准。
- 内置 `data/draws.json` 是来自 `Number-selection-tool` 的前6码快照。一键同步读取 `https://whitworthbassalips894-crypto.github.io/Number-selection-tool/data/draws.json`，因此依赖该网站继续更新、跨域可用及网络畅通；仅追加连续有效的期号，冲突或缺口不写入。同步结果保存在本机浏览器。
- 数据源中 `2022-132` 的前6码含重复号码，按附件规则排除。历史数据过少时如算法无法生成7码，该期回放也会跳过。期号按附件的年内序号规则推算，购买前请核对官方期号。
- 历史回放只使用每期之前的有效数据，重现当期号码并按前6码核对，属于事后模拟，并非实际历史投注。
- 按用户要求，页面初始化时删除当前浏览器本工具的快乐8手动记录及玩法设置；新数据采用独立存储键。其他设备不受影响。
- 如用 GitHub Pages 部署，请使用静态网站方式访问（本地可运行 `python3 -m http.server 8000`），一键同步需联网。

运行自检：`node --test tests/*.test.cjs`。
