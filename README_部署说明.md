# 快乐8每日选号工具 · 部署说明

## 部署到 GitHub Pages
1. 打开本 GitHub 仓库，确认根目录包含 `index.html`、`manifest.json`、`sw.js`、`data/kl8-latest.json`。
2. 进入仓库 **Settings → Pages**，在 **Source** 选择 `Deploy from a branch`，分支选 `main` / `/ (root)` 并保存。
3. 等待约 1 分钟后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

## 日常使用
- 每天打开页面即可直接查看下一期 **每日 5 注快乐8选号方案**（1 注随机机选 ＋ 4 注精选策略），顶部可一键切换 **选一～选十**（默认选十），并支持一键复制全部 5 注。
- 开奖后可点击「4. 数据同步」中的 **🔄 一键同步** 拉取仓库最新开奖 JSON，或在「2. 录入开奖」中直接粘贴/点选 20 个开奖号码保存。
- 手动追加的数据保存在当前浏览器的 `localStorage`；更换设备前可使用「导出手动数据」备份。
